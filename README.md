# Nokia Lumia 730 (Superman) AOSP 11 device tree

Experimental Android 11 device configuration for the Nokia Lumia 730 Dual SIM
(RM-1040, `superman`) using Qualcomm MSM8226. It contains device integration,
diagnostic tools, and packaging helpers; it is not a functional or deployable
Android image.

The tree is intended for `device/nokia/superman` in an Android 11 source
checkout. Generated images, Microsoft firmware, partition dumps, and device
backups are intentionally excluded.
